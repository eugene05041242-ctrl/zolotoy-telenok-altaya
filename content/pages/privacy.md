## 2. Какие данные и зачем обрабатываются

| Цель | Какие данные | Основание |

| Оптовая заявка | Имя, контакт, наименование организации, реквизиты | Заключение и исполнение договора |

Сайт не собирает специальные категории персональных данных и биометрические персональные данные.

## 3. Кому передаются данные

- Поставщику услуг размещения сайта (хостинг на территории Российской Федерации).
- Службам доставки — только в объёме, необходимом для доставки заказа.
- Сервису веб-аналитики — только обезличенные данные о посещении и только после согласия на использование файлов cookie.

Первичный сбор персональных данных граждан Российской Федерации ведётся с использованием баз данных, расположенных на территории Российской Федерации.

## 4. Сроки и прекращение обработки

Данные обрабатываются до достижения цели обработки либо до отзыва согласия. По обращениям покупателей — не дольше срока, необходимого для ответа и разрешения спорной ситуации.

## 6. Файлы cookie

Сайт может использовать файлы cookie для работы интерфейса и для статистики посещений. Статистика подключается только после вашего согласия. Необходимые для работы сайта файлы cookie используются всегда.
